# KlipperVision

An open-source, local AI-powered print monitoring system for Klipper.

## Goals

- Detect spaghetti failures
- Detect detached prints
- Detect nozzle blobs
- Monitor print progress
- Integrate with Moonraker
- Pause or cancel failed prints automatically
- Run completely locally
- Support multiple printers

## Planned Features

- Live webcam
- Local AI inference
- Notifications
- Plugin architecture
- Web dashboard
- Time-lapse generation
